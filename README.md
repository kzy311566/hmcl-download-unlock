# hmcl-download-unlock

本仓库自动跟踪上游 [HMCL](https://github.com/HMCL-dev/HMCL) 的 release，
并在其源码回滚[在中国大陆地区禁用游戏下载功能- #7017](https://github.com/HMCL-dev/HMCL/pull/7017)，构建 **针对#7017的回滚版本**。

> [!NOTE]
> 本仓库不是官方仓库，只提供 **针对中国大陆地区离线用户无法下载MC客户端的回滚版本**。
> 原项目版权、代码与维护归上游作者及贡献者所有。如需完整功能，也可直接使用
> [上游官方版本](https://github.com/HMCL-dev/HMCL)。
